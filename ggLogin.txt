    4. Luồng hoạt động (Workflow) - Dễ hiểu nhất
    Đây là kịch bản phổ biến nhất: "Đăng nhập bằng Google".
        + Yêu cầu: Người dùng click vào nút "Login with Google" trên Web bán hàng của bạn.
        + Chuyển hướng: Web của bạn (Client) nói: "Tôi không giữ mật khẩu, hãy sang Google mà đăng nhập" -> Trình duyệt chuyển hướng người dùng sang trang của Google.
        + Hỏi ý kiến: Người dùng đăng nhập thành công tại Google. Google hiện bảng: "Ứng dụng Bán Giày muốn xem Email và Tên của bạn. Cho phép không?"
        + Cấp mã tạm: Nếu người dùng bấm OK, Google gửi trả lại cho Web của bạn một cái mã tạm thời gọi là Authorization Code.
        + Đổi mã lấy Token: Web của bạn (Server backend) cầm cái Code này, bí mật liên hệ với Google Server: "Đây là Code người dùng vừa đưa, hãy đưa cho tôi chìa khóa (Token) thật sự".
        + Nhận Token: Google kiểm tra Code hợp lệ và trả về Access Token.
        + Truy cập dữ liệu: Từ giờ, Web của bạn dùng Access Token này để gọi API lấy thông tin (email, tên) từ Google mà không cần hỏi lại người dùng.

    lý do OAuth2 an toàn
        - Không lộ Password: Shoes Shop không bao giờ nhìn thấy, không bao giờ lưu mật khẩu Google của user. Dù Shoes Shop có bị hack, hacker cũng không lấy được mật khẩu Google của user.
        - Quyền hạn giới hạn (Scope): Khi đăng nhập, Google chỉ cho phép Shoes Shop lấy email và profile. Shoes Shop không thể đọc trộm email trong Gmail hay xem ảnh trong Google Photos (trừ khi user cấp thêm quyền).
        - Token có thể bị thu hồi: Nếu user mất điện thoại, họ có thể vào cài đặt Google và bấm "Đăng xuất khỏi Shoes Shop". Ngay lập tức cái Token cũ bị vô hiệu hóa, Shoes Shop không thể truy cập dữ liệu được nữa.
1. Luồng hoạt động (Logic Flow)
    Quy trình này tuân theo chuẩn OAuth 2.0 và mô hình Client-First (Frontend lấy token, Backend xác thực).
        - Client (Người dùng): Bấm nút "Đăng nhập bằng Google".
        - Google: Hiện Popup, người dùng chọn tài khoản Gmail.
        - Google -> Client: Trả về một chuỗi mã hóa gọi là Credential (ID Token).
        - Client -> Server (Backend): Gửi chuỗi Credential này qua API (ví dụ: POST /api/auth/google).
        - Server: Dùng thư viện Google để giải mã Credential
            + Kiểm tra: Token này có phải do Google cấp không? Có phải cấp cho App của mình (Client ID) không?
            + Lấy info: Nếu đúng, lấy ra Email, Tên, Avatar.
        - Server (Database): Kiểm tra Email trong Database:
            + Trường hợp 1 (Đã có): Lấy thông tin user đó ra.
            + Trường hợp 2 (Chưa có): Tự động tạo user mới (Register ngầm) với email đó -> Lưu vào DB.
        - Server -> Client: Tạo JWT (AccessToken) của hệ thống bạn và trả về cho Client.
        - Client: Lưu JWT, cập nhật Redux và chuyển hướng vào trang chủ (Hoàn tất).
2. Các bước thực hiện chi tiết
    Bước 1: Cấu hình Google Cloud (Lấy "Chìa khóa")
        + Truy cập Google Cloud Console.
        + Tạo Project mới.
        + Vào APIs & Services > Credentials -> Tạo OAuth Client ID.
        + Chọn Web application.
        + Phần Authorized JavaScript origins: Điền http://localhost:3000 (quan trọng để test local).
        + Copy Client ID (dạng ...apps.googleusercontent.com).
    Bước 2: Cài đặt thư viện
        + Backend: npm install google-auth-library
        + Frontend: npm install @react-oauth/google
    Bước 3: Code Backend (Server)
        - Service (authService.ts): Viết hàm loginGoogleService.
            + Dùng OAuth2Client để verifyIdToken.
            + Lấy email, picture, name từ payload.
            + Dùng findOneBy({ email }) để tìm user.
            + Nếu chưa có -> userRepository.create(...) (tạo password ngẫu nhiên).
            + Cuối cùng gọi generateTokens để trả về token hệ thống.
        - Controller (authController.ts): Viết hàm loginGoogle.
            + Lấy req.body.credential.
            + Gọi Service và trả kết quả JSON về.
        - Route (authRoutes.ts):
            + Thêm router.post("/google", loginGoogle).
    Bước 4: Code Frontend (Client)
        - Service (authService.ts frontend):
            Viết hàm gọi API: axios.post("/auth/google", { credential }).
        - Giao diện (login/page.tsx):
            Bọc GoogleOAuthProvider với clientId vừa lấy ở Bước 1.
            Dùng component <GoogleLogin />.
            Trong sự kiện onSuccess:
                Lấy credentialResponse.credential.
                Gửi xuống Backend.
                Nhận về JWT -> Dispatch loginSuccess vào Redux.
                Redirect về trang chủ.
    Tóm tắt sự khác biệt chính với Login thường:
        Login thường: Bạn gửi email + password -> Server check password hash.
        Login Google: Bạn gửi Google Token -> Server check chữ ký Token (verify) -> Tin tưởng email trong đó là thật.
